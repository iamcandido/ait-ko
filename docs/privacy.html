AiT.KO – Privacy Policy

Last updated: October 22, 2026

AiT.KO is a browser extension that lets Okta administrators describe a user search in plain language, turns it into an Okta search filter, runs it against the administrator's own Okta organization, and lets them export the results to CSV. This policy explains what data the extension handles and where it goes.

In short: the developer does not operate any server, does not collect any data, and does not receive any data from the extension. The only data that leaves your browser, other than requests to your own Okta organization, is the text of your request and your API key, which are sent to the AI provider that you choose and configure.

3. What we do not do

  • We do not run any server and do not receive, collect, or have access to your data, your requests, or your API key.
  • We do not use analytics, tracking, advertising, or crash-reporting services.
  • We do not sell or transfer user data to third parties, and we do not use it for any purpose unrelated to the extension's single purpose.
  • We do not use or transfer user data to determine creditworthiness or for lending purposes.
  • We do not load or execute remotely hosted code.
  • We do not send Okta user data to AI providers. Only the text of your request is sent.

The extension's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

4. Third-party AI providers

When you click "Generate filter", the text you typed is sent directly from your browser to the provider you selected in the extension options:

  • Google Gemini API, subject to Google's terms and privacy policy. Please note that Google's terms for free-tier usage may allow content submitted to be used to improve Google's products. Check Google's current Gemini API terms for details.
  • Anthropic Claude API, subject to Anthropic's commercial terms and privacy policy.

We do not control how these providers handle data. Do not include personal data (such as a specific person's name or email address) in your requests unless you are comfortable with it being processed by the selected provider. Generic requests such as "active users in the Finance department with country code PT" contain no personal data.

5. Permissions and why they are needed

  • storage: to save your API key, provider, and model choice locally.
  • Access to *.okta.com and *.oktapreview.com: to display the AiT.KO panel on the Okta Admin Console and to call your own Okta organization's user API with your existing session. The panel activates only on hostnames that contain -admin.; on all other Okta pages it does nothing.
  • Access to generativelanguage.googleapis.com: to send your request text to the Google Gemini API, if you select that provider.
  • Access to api.anthropic.com: to send your request text to the Anthropic API, if you select that provider.

6. Security

  • The extension only performs read (HTTP GET) requests against the Okta user API.
  • The filter produced by the AI provider is validated before it runs: only a fixed set of attributes and search operators is accepted, and anything else is rejected. You can see and edit the filter before running it.
  • Results are rendered as plain text, never as HTML, and CSV exports neutralize spreadsheet formula injection.
  • Your API key is stored in the browser's extension storage, which is not encrypted at rest. Anyone with access to your browser profile on disk could read it. We recommend using a dedicated key that you can revoke at any time.

7. Retention and deletion

The extension keeps no data other than your API key, provider, and model name, all stored locally. You can delete them at any time by clearing the fields on the options page, or by removing the extension, which deletes all of its local data. Data held by an AI provider is governed by that provider's policies.

8. Children

AiT.KO is a tool for IT administrators and is not directed at children.

9. Changes to this policy

If the extension's data practices change, this page will be updated and the "Last updated" date above will change. Material changes will be reflected in the extension's Chrome Web Store listing.
